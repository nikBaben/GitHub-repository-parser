# Конфигурация

Настройки загружаются через `pydantic-settings` из переменных окружения и файла
`.env`.

Класс настроек находится в:

```text
infrastructure/github/config.py
```

## Пример `.env` 
Лежит в  `.env.example` 
## Переменные

| Переменная | Обязательная | Значение по умолчанию | Описание |
| --- | --- | --- | --- |
| `TOKEN` | Да | - | GitHub token для авторизации. |
| `GITHUB_URL` | Да | - | URL анализируемого репозитория. |
| `GITHUB_API_URL` | Нет | `https://api.github.com` | Базовый URL GitHub REST API. |
| `GITHUB_API_VERSION` | Нет | `2026-03-10` в коде | Версия GitHub API. |
| `DEFAULT_TIMEOUT` | Нет | `40` | Таймаут HTTP-запросов в секундах. |
| `DEFAULT_PER_PAGE` | Нет | `100` | Количество элементов на страницу. |
| `DEFAULT_RETRIES` | Нет | `4` | Количество повторных попыток. |
| `DAYS` | Нет | `10` | За сколько последних дней брать историю. |
| `HISTORY_CACHE_TTL_SECONDS` | Нет | `3600` | Время актуальности кэша в секундах. |
